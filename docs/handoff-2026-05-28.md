# 引き継ぎメモ 2026-05-28

## プロジェクト概要

toC向けスクール事業の無料面談・相談会予約システム。複数プロジェクトごとに
担当ホストを設定し、ホストの Google カレンダー空き状況と同期して、
ゲストが1対1面談を予約できる内製ツールを作る。

技術スタックは Next.js App Router + TypeScript + Tailwind CSS + Auth.js +
Prisma + PostgreSQL。ローカルDBは Docker Desktop 上の PostgreSQL。

## 設計上の重要判断

- Google Calendar の空き判定はDB同期ではなく、予約表示時と確定直前に
  FreeBusy API を照会する。
- 予約確定時は内部ステータス `HELD` を作り、DB制約で競合を防いでから
  Google Calendar イベントを作成する方針。
- Google OAuth トークンは本実装ではDBに暗号化保存する。
- 予約者PIIは暗号化保存し、メール重複検索には平文ハッシュではなく
  秘密鍵付き HMAC を使う方針。
- Auth.js 標準 Prisma Adapter はトークン平文保存になり得るため、
  そのまま接続せず、暗号化保存方針を保った実装にする。
- 予約競合の最終防衛線として PostgreSQL exclusion constraint を使う。

## 次にやるべきこと

次は「プロジェクト作成画面をDB保存できるようにする」のがよい。

理由:

- すでに `Project`, `ProjectHost`, `ProjectAvailability`, `FormField` の
  スキーマと seed がある。
- `/admin/projects/new` はフォームUIだけあるが、まだ保存しない。
- ここを実装すると、管理画面で作ったプロジェクトが一覧と公開ページへ反映される。
- その後、予約者フォームのDB保存、空き枠計算、Google Calendar連携へ進めやすい。
